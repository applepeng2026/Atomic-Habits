# atomic-habits · 微习惯养成 Skill

基于 James Clear《原子习惯》（Atomic Habits）的行为科学教练。把用户模糊的愿望（"我想早起/读书/健身/存钱"或"我想戒刷手机/拖延/吃零食"），拆解成"微小到不可能失败"的具体行动，降低对意志力的依赖。

## 一句话简介

告诉它你想养成或改掉的习惯，它用身份设计 + 习惯叠加 + 两分钟规则 + 环境设计，给你一份能立刻开干、不靠毅力的行动方案。

## 适用人群

- 想养成习惯却总"坚持不下去"的普通人
- 想改掉坏习惯（刷手机、拖延、零食）的人
- 做自律 / 成长类内容、需要一套可复用的习惯方法论的创作者

## 安装

把整个 `atomic-habits/` 目录放入：

```
~/.workbuddy/skills/atomic-habits/
```

目录结构：

```
atomic-habits/
├── SKILL.md                          # 调度 + 核心约束 + 输出规范 + 边界兜底
├── README.md                         # 本文件
└── references/
    ├── atomic-habits-playbook.md     # 四定律、身份设计、叠加、两分钟、环境、坏习惯反转、避坑
    └── examples.md                   # 3 个完整输入输出范例
```

## 使用方法

说出触发词即可调用，例如：

- "帮我养成每天读书的习惯"
- "怎么改掉睡前刷手机"
- "坚持不下去怎么办"
- "用两分钟规则给我拆一下健身"

模型会先确认关键两点（想养成/改掉什么、有什么日常习惯可绑定），再按规范输出。

## 输出示例（节选）

```
⛓️ 习惯叠加公式
继 [现有习惯] 之后，我将 [新习惯的第一步]。

⏱️ 两分钟版本
（两分钟内可完成的动作）

🌍 环境设计建议
（一条具体可执行的物理/数字环境调整）
```

完整范例见 `references/examples.md`。

## 注意事项

- 本 skill 不靠"喊坚持"，核心是**系统、身份、环境**，降低意志力消耗。
- 坏习惯用"四步反转"处理，而非简单说"别做"。
- 错过一天没关系，避免"全有或全无"思维。
